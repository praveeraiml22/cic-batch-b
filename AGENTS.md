- New uploads (assignments, documents, resumes, home-notice PDFs) go to private Backblaze B2 via src/lib/b2.server.ts; DB path columns store "b2:<key>" and paths without that prefix are legacy Supabase Storage objects — lets both coexist without a data migration.
- Realtime: public.assignments, public.document_folders and public.assignment_topics are on the supabase_realtime publication; the admin Assignments tab subscribes with a per-mount random channel name and invalidates its queries on change — add new streamed tables to the publication via migration, never reuse an open channel name.
- Assignment management: admin-created topics (public.assignment_topics, deadline + attachments) drive student submissions; students attach files via public.assignment_files and link rows through assignments.topic_id. Deadline enforcement is server-side in both the upload route and submitTopicAssignment. Deleting a topic (deleteAssignmentTopic) removes every stored file before the rows.
